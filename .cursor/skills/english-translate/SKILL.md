# 和文の英訳

日本語を英語にするときに使う。口語、自然、ネイティブ、と書いてなくても、その場で英語圏の人が口にする文で返す。書き言葉の直訳にしない。友達同士の場面を、改まった文で埋めない。

訳は一度だけ出す。英語を先に、その直下に、選んだ言い方の要点を日本語で短く書く。同じ文を繰り返さない。音のつながりで気を付ける点があれば、一つか二つ短く足す。無いときは足さない。
